# Безопасность

Инструмент не имеет почтового или сетевого транспорта, SMTP-отправки, IMAP-записи, SDK моделей или доступа к каким-либо рабочим БД. Команды работают только с явно переданными локальными файлами и выбранным state. Реальная почта при разработке и тестировании не подключалась.

Входящие EML недоверенные. Проверяются единственные From/To/Date/Message-ID, отсутствие дублированных ключевых заголовков и управляющих символов, точный адрес поставщика, текущий месяц и цепочка явно зарегистрированных Sent-ID. Подтверждение адреса не аутентифицирует отправителя: для импортированных EML доверенная сторона должна проверить источник отдельно. Дата письма тоже является заявлением отправителя.

Ограничения: EML 16 МиБ, не более 64 MIME-частей; вложение 64 байта - 10 МиБ; XLSX не более 256 ZIP-записей, 20 МиБ суммарно распакованного, 4 МиБ на запись, коэффициент сжатия не выше100; не больше32 листов. Имена файлов не могут содержать разделители пути, управляющие символы или двоеточие. В ZIP блокируются traversal, symlinks, дубли без учёта регистра, шифрование, исполняемые/неизвестные бинарные части, макросы, внешние связи и подписи. XML не исполняется. Формулы не вычисляются и консервативно отвергаются. XLS проверяется по CFB-streams и BIFF, затем xlrd; VBA, внешние книги, шифрование и не-sheet BOUNDSHEET запрещены. Безопасные сложные книги могут быть отклонены: исходник остаётся в raw, требуется ручная проверка, а не отключение защиты.

Нет распаковки файлов ZIP на диск, Excel/LibreOffice, shell-исполнения входа или загрузки URL. HTML поставщика не переносится в исходящие HTML: черновики plain text, с текстовой цитатой. Заголовки берутся из проверенной конфигурации и проверенных ID. Оригинал EML и допустимое вложение сохраняются по SHA-256 с fsync без перезаписи; несовпадение при повторе блокирует действие. Отвергнутый файл остаётся внутри неизменённого EML. Повтор REVIEW только явным retry, а не автоматическим повтором внешнего действия.

State, его родительские каталоги, конфигурация и import receipt должны быть доверенными и доступны только владельцу. Программа блокирует symlink и выход сохранённых путей за state, но не обещает защиту от одновременного вмешательства другого процесса того же пользователя/root. Оригиналы0400 не являются WORM-носителем. Tracker - локальный атомарно заменяемый JSON с историей событий, без криптографической защиты журнала и без распределённых транзакций. Нужны обычные пользовательские резервные копии state. Не размещай state внутри публичного дерева source.

ack-import проверяет привязку подтверждения, а не внешнюю БД. Только владелец/доверенный importer имеет право выдавать SUCCESS после реального импорта. Demo с --simulate-import специально создаёт учебное подтверждение; оно не доказывает реальную загрузку.

Не публикуй уязвимости вместе с реальными письмами/адресами/вложениями/секретами. Для воспроизведения используй синтетический .example-пример и минимальный тест. Прежде чем подключать этот инструмент к рабочей среде, проведи отдельную проверку прав, источника EML и политики хранения. Антивирус и песочница для открытия документов остаются отдельными средствами защиты.
